# Polices des écrans

Les polices que le moteur web de l'original charge de Google Fonts (jeu latin), reprises telles quelles pour
redessiner les écrans des paris (ecrans_paris.gd) :

- `barlow-600.woff2`, `barlow-700.woff2` : Barlow, de Jeremy Tribby ;
- `limelight.woff2` : Limelight, de Eduardo Tunni.

Toutes deux sont distribuées sous la SIL Open Font License 1.1 (https://openfontlicense.org).
